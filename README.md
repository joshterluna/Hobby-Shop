# Hobby-Shop
A Java CLI-based management system for a hobby shop specializing in blind boxes and collectible figurines.

## Introduction

Aetherion (Hobby-Shop) manage its inventory, sales, and customer collections from the command line. Admins manage users and products, shop staff handle stock and walk-in sales, and customers can browse the catalog, buy items, and track their own collection. All data is saved in text files, so it persists between program runs.
